## 📖 על הפרויקט

כרטיסיות הן הרכיב הנפוץ ביותר בעיצוב אתרים מודרניים להצגת מוצרים, פרופילי משתמשים, מאמרים ופורטפוליו.  
פרויקט זה נבנה עבור תלמידי החוג ומציג **קובץ עצמאי אחד (`index.html`)** המאפשר לבחון כל אפקט בצורה חיה, לקרוא הסבר בעברית, ולראות את תחביר פקודת ה-CSS המפעילה אותו.

### יתרונות הפרויקט:
* **Zero Dependencies:** אין צורך בהתקנת ספריות JS או frameworks – הכל פועל באמצעות HTML ו-CSS בלבד.
* **רספונסיביות מלאה:** התאמה לכל מכשיר (נייד, טאבלט, מסך מחשב).
* **מניעת רענון דף:** כל הקישורים הפנימיים מנוטרלים (`e.preventDefault()`) כך שאינם קופצים לראש העמוד בעת לחיצה.

## 🎯 טבלת 15 האפקטים והפקודות המרכזיות

| # | שם הכרטיסייה / האפקט | פקודת CSS מרכזית | תיאור קצר |
|---|---|---|---|
| **1** | שכבות טקסט תלת-ממדיות | `attr(data-text) + -webkit-text-stroke;` | שכפול טקסט עם צבעים נפרדים שנפרדים בתלת-ממד |
| **2** | כרטיסיית שכבות גולשת | `clip-path: circle(...) at 80% 20%;` | חיתוך מעגלי שמתרחב ומציף את הכרטיס בגרדיאנט |
| **3** | דמות פורצת מהכרטיס | `img: height 320px -> 420px; bottom: 20px;` | דמות שמגדילה את גובהה ופורצת מחוץ לגבולות הכרטיס |
| **4** | כרטיסיית חצאים (Split Card) | `face1: width/height 90px; border-radius: 50%;` | שכבה ראשונה מתכווצת לעיגול עליון והתוכן נחשף |
| **5** | שתי תיבות מתמזגות | `face1: translateY(100px); face2: translateY(-100px);` | שתי שכבות הנעות מכיוונים נגדיים ומתאחדות במרכז |
| **6** | פרופיל עם מסגרת נופלת | `clip-path: polygon(...); img: top 20px;` | מסגרת זוויתית עליונה שמשתנה והתמונה מתכווצת |
| **7** | כותרת נפתחת (Post Overlay) | `img: opacity 0.3; content: translateY(0);` | התמונה מחשיכה והכותרת והפסקה גולשות מתחתית הכרטיס |
| **8** | כרטיסיית Glass Profile | `rotateX(10deg -> 0deg); backdrop-filter: blur(10px);` | כרטיס זכוכית עם הטיית עומק ואייקונים שמרחפים בהובר |
| **9** | היפוך תלת-ממדי מלא (3D Flip) | `transform-style: preserve-3d; rotateY(180deg);` | סיבוב של 180 מעלות בציר ה-Y לחשיפת גב הכרטיסייה |
| **10** | זרקור מעקב זוהר (Border Beam) | `conic-gradient(...) + rotate(360deg);` | קרן אור מעגלית שמסתובבת ברציפות סביב הגבול |
| **11** | כרטיסיית מגירה נשלפת | `translateY(65% -> 0); cubic-bezier(...);` | חלונית מידע תחתונה שנשלפת כמו מגירה עם סיומת קפיצית |
| **12** | כרטיסיית גל נוזלי (Blob) | `border-radius: 40% 60% 70% 30% / 40% 50% 60% 50%;` | שכבת רקע אמורפית המשתנה ברציפות במעגל |
| **13** | מסגרת קו נמתחת (Border Trace) | `span.line: width / height -> 100%;` | ארבעה קווים הנמתחים מהקצוות וסוגרים מסגרת שלמה |
| **14** | מראה חלבי רדיאלי (Radial Glow) | `radial-gradient(circle at center, ...); scale(1.3);` | הילת גרדיאנט שמתפשטת מהמרכז ומבליטה את התוכן |
| **15** | כרטיסיית פירוק שכבות | `rotate(±10deg) + translateZ(30px);` | פירוק הכרטיסיה ל-3 שכבות נפרדות במרחב התלת-ממדי |
